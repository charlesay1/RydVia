# Manrope

Variable font from the official Google Fonts repository:
https://github.com/google/fonts/tree/main/ofl/manrope

Source: `Manrope[wght].ttf`, stored locally as `Manrope.ttf`.
License: included `OFL.txt` (SIL Open Font License).
SHA256: `3ae11c49db0455a3cc33e37d380f20fdb8c7f8b41dc07625c177e3d87a9d6ae6`.

Flutter and Next.js consume this single source. Font requests are local to each
application deployment, with no runtime Google Fonts dependency. This is interface
typography and is not the approved custom RydVia logo wordmark.
