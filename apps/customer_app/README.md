# RydVia Customer

Native identity: `com.rydvia.customer`. Uses the shared `rydvia_auth` flow for
welcome, OTP, onboarding, session gating, and appearance. Customer services are
backend-fed; bookings, tracking, wallet, and payment workflows are not yet enabled.

From this directory: `flutter run --dart-define-from-file=../../.env`.
See [setup](../../docs/setup/DEVELOPMENT.md) and [build status](../../docs/BOOTSTRAP_REPORT.md).
Approved launcher artwork and production SMS/backend verification remain required.
