# RydVia Driver

Native identity: `com.rydvia.driver`. Uses the shared welcome/OTP/onboarding flow
and server-backed Driver approval gate. Ride/delivery/logistics/towing jobs,
navigation, earnings, and payout workflows are not yet enabled.

From this directory: `flutter run --dart-define-from-file=../../.env`.
See [setup](../../docs/setup/DEVELOPMENT.md) and [build status](../../docs/BOOTSTRAP_REPORT.md).
Approved launcher artwork and production SMS/backend verification remain required.
